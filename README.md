#  Go Technical Interview Mentor Bot

Production-ready Telegram-бот для подготовки к техническим собеседованиям по **Golang** (грейды: *Intern*, *Junior*, *Middle*, *Senior*). 

Поддерживает голосовые ответы, симуляцию реального собеседования с наводящими вопросами от ИИ-техлида и алгоритм адаптивного интервального повторения.

 **Живой бот в Telegram:** [@go_SikkiMentor_bot](https://t.me/go_SikkiMentor_bot)

---

##  Ключевые возможности

* **🎙 Голосовые ответы (Voice-First):** Стриминг и транскрибация голосовых сообщений любой длительности через **Deepgram Nova-2 API**.
* **🧠 AI-ревью ответов:** Оценка ответа по 10-балльной шкале, подробный разбор пробелов и сопоставление с эталонными техническими критериями (на базе DeepSeek / Groq).
* **🎓 Режим Mock-собеседования:** Имитация полного технического интервью (~40 минут). ИИ выступает в роли требовательного техлида: задает наводящие и углубляющие вопросы при неполных ответах, а в финале формирует структурированный вердикт (**Hire / No Hire**, подтвержденный грейд, зоны роста).
* **📚 База знаний:** 85 тем и более 860 проверенных вопросов с эталонными ответами и синтаксической подсветкой кода.
* **⚡ Блиц-квиз:** Более 1 680 практических задач по коду с 4 вариантами ответов и детальным объяснением.
* **🔁 Адаптивная колода (Spaced Repetition):** Алгоритм ранжирует вопросы на основе персональной истории ответов — слабые темы возвращаются в начало очереди до закрепления материала.

## 🛠 Технологический стек

* **Язык:** Go 1.23
* **База данных:** PostgreSQL 16 (драйвер `pgx/v5` с пулом соединений)
* **Кэш и сессии:** Redis 7 (состояния FSM, активные сессии интервью, TTL)
* **Миграции:** `golang-migrate`
* **Фреймворк бота:** `telebot.v3`
* **AI & Speech-to-Text:** Deepgram API, DeepSeek API, Groq Cloud API
* **Контейнеризация:** Docker Compose (Multi-stage сборка, Alpine Linux)

## 🏛 Архитектура проекта

Проект спроектирован по принципам **Clean Architecture** (Чистая Архитектура):

```text
├── cmd/
│   ├── bot/                 # Точка входа приложения
│   └── seeder/              # Утилита наполнения базы знаний
├── internal/
│   ├── domain/              # Сущности, контракты и доменная логика
│   ├── usecase/             # Бизнес-сценарии (интервью, mock, квизы, прогресс)
│   ├── repository/
│   │   ├── postgres/        # Реализация репозиториев PostgreSQL
│   │   └── redis/           # FSM и стейт сессий в Redis
│   ├── delivery/
│   │   └── telegram/        # Хэндлеры событий Telegram, клавиатуры и view
│   ├── ai/                  # Клиенты нейросетей и Speech-to-Text
│   └── config/              # Загрузка и строгая валидация конфигурации
├── migrations/              # SQL-миграции схемы БД
├── docker-compose.yml       # Локальное окружение для разработки
└── docker-compose.prod.yml  # Продакшен-конфигурация (hardening)
```

### 🔒 Безопасность и надежность (Production Hardening):
* Контейнеры запускаются под непривилегированным пользователем (`appuser`).
* Защита контейнера: `read_only: true`, `cap_drop: ALL`, `no-new-privileges: true`, монтирование временных файлов в `tmpfs`.
* Встроенные `healthcheck` для PostgreSQL и Redis с автоматическим контролем порядка старта сервисов.
* Graceful Shutdown с закрытием активных сессий и соединений пула.

## 🚀 Быстрый старт (Локально)

### 1. Клонирование репозитория
```bash
git clone https://github.com/powood/Tg_GO_Mentor.git
cd Tg_GO_Mentor
```

### 2. Настройка переменных окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Заполните обязательные переменные в `.env`:
* `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather)
* `DEEPSEEK_API_KEYS` — API-ключ к LLM
* `GROQ_API_KEYS` — API-ключи Groq
* `DEEPGRAM_API_KEY` — ключ Deepgram для распознавания голоса

### 3. Запуск через Docker Compose
```bash
docker compose up -d --build
```

Бот автоматически применит миграции базы данных и запустится в режиме Long Polling.
